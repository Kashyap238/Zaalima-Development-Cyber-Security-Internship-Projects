# Docker Deployment

## Build Docker Image

```bash
docker build -t llm-security-gateway .
```

## Run Docker Container

```bash
docker run -p 8000:8000 llm-security-gateway
```

## Benefits

- Consistent deployment
- Environment isolation
- Easy scaling
- Cloud ready architecture

## Project Usage

The Enterprise LLM Security Gateway can be packaged and deployed using Docker containers for portability and simplified deployment.
