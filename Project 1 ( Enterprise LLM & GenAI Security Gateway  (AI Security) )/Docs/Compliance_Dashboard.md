# Compliance Dashboard

## Purpose

The Compliance Dashboard provides security teams with a centralized view of AI security activity.

## Metrics

- Total Requests
- PII Detections
- Prompt Injection Attempts
- Blocked Requests

## Benefits

- Security Monitoring
- Compliance Reporting
- Threat Visibility
- Usage Analytics
