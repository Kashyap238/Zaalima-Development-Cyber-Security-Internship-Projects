# Enterprise LLM & GenAI Security Gateway

## Objective

Develop a secure gateway that protects Large Language Models from data leakage and prompt injection attacks.

## Features

- PII Detection
- Data Redaction
- Prompt Injection Detection
- Audit Logging
- Dashboard Monitoring

## Technologies

- Python
- FastAPI
- PostgreSQL
- Redis
- Microsoft Presidio
