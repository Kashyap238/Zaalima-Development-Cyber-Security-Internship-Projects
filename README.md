## Projects

### Project 1: Enterprise LLM & GenAI Security Gateway (AI Security)

A secure gateway designed to protect Large Language Model (LLM) interactions by detecting sensitive information, preventing prompt injection attacks, and maintaining audit logs.

**Key Features**

* PII Detection
* Data Redaction
* Prompt Injection Detection
* Audit Logging
* Dashboard Monitoring

---

### Project 2: Identity Threat Detection and Response (ITDR) Platform

A cybersecurity platform focused on monitoring identity-based threats, suspicious login activity, privilege escalation, and account compromise attempts.

**Key Features**

* Identity Monitoring
* Threat Detection
* Behavioral Analytics
* Blast Radius Analysis

---

### Project 3: Automated Ransomware Containment & Incident Response Orchestrator

An automated incident response system designed to detect, contain, and respond to ransomware-related security incidents.

**Key Features**

* Alert Ingestion
* Host Isolation
* Evidence Collection
* Incident Response Automation
